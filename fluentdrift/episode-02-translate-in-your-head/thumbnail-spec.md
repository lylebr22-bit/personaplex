# Thumbnail Spec - Episode 2

Re-use the Episode 1 `thumbnail.html` template. Three swaps:

1. **Subject (left side):** swap the breakthrough graphic for a
   silhouetted head profile with two thought bubbles - one
   showing text (greying out), one showing an image (glowing
   gold). Visual metaphor: words being replaced by pictures.

2. **Headline (right side):** swap "BREAK THE PLATEAU" for
   **"STOP TRANSLATING"** (3 words, same Anton font, same red
   slash through "TRANSLATING").

3. **Stamp (bottom-right):** swap "[X] B1" for **"3 MIN FIX"**.

Everything else (navy background, gold accents, brand watermark,
grain) stays identical. Brand consistency across the thumbnail
grid is a subscriber-conversion driver.

## Quick build

Copy `episode-01-plateau-breaker/thumbnail.html` to this folder
and apply the 3 changes above. Export at 1280x720.
