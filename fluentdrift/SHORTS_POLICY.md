# YouTube Monetization Compliance - Shorts Edition (2026)

This file is the gate. Every Short and every long-form must pass
this checklist before upload, no exceptions. The July 2025 policy
update (renamed "repetitious content" to "inauthentic content")
made it possible for a single bad upload to demonetize an entire
channel. We do not test that boundary.

## Hard rules - violating any of these = do not upload

1. **AI voice disclosure ON.** YouTube Studio toggle "Altered or
   synthetic content" must be enabled at upload for every video
   that uses ElevenLabs or any AI voice.
2. **No deepfakes of real people.** No AI avatars of named real
   individuals. Anonymous mouth silhouettes are fine.
3. **Original script.** Every Short and long-form is written by
   you (or generated and then meaningfully edited by you).
   Pasting a Reddit/Wikipedia text into ElevenLabs = ban risk.
4. **No mass-produced templates.** Do not upload more than 3
   videos in a row using the identical visual template, voice,
   and structure with only the topic swapped.
5. **Human editorial input is provable.** Each video has an
   editorial decision visible: a unique angle, an original opinion,
   a re-organized argument, a hand-picked example.
6. **Citations for stats.** Every numerical claim has a real
   source. We watermark the source in-frame on Shorts (8% opacity,
   bottom corner) and link it in the description on long-form.
7. **No AI-generated photoreal content presented as real.** AI
   visuals must be clearly stylized (animations, motion graphics,
   silhouettes) OR explicitly labeled.

## Per-video checklist

Run this for every Short and every long-form before clicking publish.

```
[ ] Title under 60 chars (Shorts) / under 70 chars (long-form)
[ ] Description has at least 100 words of human-written context
[ ] Hashtags: 3-5, niche-relevant, not banned/shadowed
[ ] Tags: 8-15, mixed broad + long-tail
[ ] Thumbnail uploaded (long-form) or first frame engineered (Shorts)
[ ] Captions hardcoded (Shorts) or accurate auto-captions verified (long-form)
[ ] "Altered or synthetic content" toggle ON
[ ] "Made for kids" toggle OFF (this is adult education)
[ ] Category: Education
[ ] Language: English / Audio language: English
[ ] At least one editorial element distinct from previous 3 uploads
[ ] All stats have a citation in the description
[ ] No copyrighted music without a valid license
[ ] No copyrighted clips beyond fair-use boundaries (10s max, transformative)
[ ] Loudness master at -14 LUFS (Shorts) or -16 LUFS (long-form)
```

## Channel-level rules

| Constraint                          | Limit                                |
|-------------------------------------|--------------------------------------|
| Same visual template in a row       | Max 3 uploads                        |
| Same voice + cadence in a row       | Max 7 uploads then cadence variation |
| Identical hook structure in a row   | Max 4 uploads                        |
| Daily upload volume                 | 1 long-form max + 2 Shorts max       |
| Weekly upload volume                | 5 long-form + 14 Shorts max          |

Going over these limits flags the channel as automated even if
each video individually passes. The "inauthentic content" policy
is graded at the channel level, not the video level.

## Pre-publish quick test (90 seconds)

Before clicking upload, ask yourself:

1. **Could a smart viewer accuse me of mass production?** If yes,
   change one structural element before uploading.
2. **Did I learn something making this video?** If no, the viewer
   probably won't either.
3. **Would I show this to a friend?** If no, fix it before publish.

If the answer to any is no, don't upload. Hold and revise.

## What to do if a video gets demonetized

1. Do not delete it.
2. Read the demonetization reason carefully.
3. File a manual review. Cite this checklist in the appeal.
4. Pause new uploads in the same template/format until the appeal
   resolves.
5. If the appeal is denied, change the template before resuming.

## What to do if the channel gets a strike

1. Stop all uploads immediately.
2. Review every video published in the prior 30 days against this
   checklist.
3. Privately unlist any video that fails the checklist.
4. Wait for appeal or strike expiry before resuming uploads.
5. After resuming, run all new content through this checklist
   plus a second human reviewer.
